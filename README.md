# HEALIX Doctor Frontend

A Vite + React frontend prototype for the HEALIX Hospital Management System, focused on the Doctor role and Patient Medical Record screen.

## Run in VS Code

1. Extract this ZIP.
2. Open the extracted `healix-doctor-frontend` folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the localhost URL shown by Vite (normally http://localhost:5173).

## Included interactions

- Doctor navigation/sidebar
- Patient search field
- Medical history tabs
- View test report modal
- Write prescription modal
- New visit/scheduling modal
- Add medication
- Quick-action buttons
- Notification toast
- Responsive layout

This is frontend-only; no database/backend is included.
